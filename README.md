# 🔍 PCB Quality Inspection System

AI-powered PCB defect detection and quality inspection system using **YOLOv8n**, Computer Vision, and Deep Learning for real-time automated manufacturing inspection.

---

# 🚀 Overview

This project focuses on automating Printed Circuit Board (PCB) quality inspection using state-of-the-art deep learning techniques. The system is capable of detecting and classifying PCB defects with industry-grade accuracy while maintaining lightweight and real-time performance.

The project leverages:

- YOLOv8n for fast and efficient object detection
- Computer Vision pipelines for preprocessing and defect localization
- Real-time inference optimization for manufacturing environments
- Automated defect detection to reduce manual inspection effort

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/pranjalmishra27/Pcb-quality-inspection.git
cd Pcb-quality-inspection
```

## Create Environment

```bash
conda create -n pcb python=3.10
conda activate pcb
```

## Install Dependencies

```bash
pip install -r requirements.txt
```
